# Step 2: 3D print the parts

Print the three `.stl` files in the [3D_Design folder](https://github.com/KravitzLabDevices/Tumbly/tree/main/extras/3D_Design):

| File | Part |
|---|---|
| `Tumbly_Base.stl` | Base |
| `Tumbly_Hopper.stl` | Rotating food hopper |
| `Tumbly_Door.stl` | Door |

> **Note:** These parts are designed for **Allentown MAX caging**. You will need to modify them for other cage types.
